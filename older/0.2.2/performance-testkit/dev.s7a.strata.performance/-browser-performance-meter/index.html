BrowserPerformanceMeter

class BrowserPerformanceMeter(plan: PerformancePlan = PerformancePlan())(source)

Browser-native clock and animation-frame execution, independent of an application's renderer. Action-to-next-frame latency is not GPU completion time or JavaScript CPU time. Closing cancels pending callbacks, releases application closures, and rejects an incomplete run.
