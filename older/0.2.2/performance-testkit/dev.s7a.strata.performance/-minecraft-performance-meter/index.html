MinecraftPerformanceMeter

class MinecraftPerformanceMeter(screen: Any, refresh: () -> Unit = {}) : AutoCloseable(source)

Actual Fabric extraction/render adapter, confined to the measured screen's client thread. Event callbacks and native counters belong to the kit; consumers supply only state changes. GPU completion, model mutation, readiness, and evidence storage are outside extraction samples. Complete operation frames include diagnostic instrumentation and frame pacing, rather than uninstrumented application latency.

Parameters

screen

actual measured Fabric screen, not a preview or replacement presenter.

refresh

application-owned state delivery before extraction.
