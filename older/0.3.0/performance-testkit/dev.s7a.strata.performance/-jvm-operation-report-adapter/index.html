JvmOperationReportAdapter

interface JvmOperationReportAdapter(source)

Optional fixture-owned supplemental report, discovered through a static operationReport() hook. Use JvmPerformanceRunner.warmup and JvmPerformanceRunner.sequence on the fixture owner thread. Preparation, assertions, serialization and surviving-resource cleanup belong outside each sample; required lifecycle work belongs inside the declared complete operation.

collectVerified

open fun collectVerified(plan: PerformancePlan, verifyWork: () -> Unit): Map<String, JsonObject>

Verifies complete fixture work before collecting by default. A fixture with a permanently terminal owner may override this boundary to run its original complete verification and collection inside one owner lifetime instead. Such an override must retain every original control and release the owner before returning; failed verification or cleanup must propagate without a successful report. verifyWork is a synchronous borrowed callback and must never be retained.
