FabricMinecraftScreen

class FabricMinecraftScreen : Screen, AutoCloseable, RuntimeUiDiagnosticsOwner, FabricMinecraftInputReset(source)

Fabric client screen backed by one common Minecraft UI host on Minecraft 1.21.8 and compatible primitive-input releases.

The host is confined to the client thread and is terminally owned by this screen. Native primitive callbacks are detached into the same typed common input protocol used by newer adapters. The optional parent is retained for navigation but is never owned or closed.
