# Demo typeface

Monocraft is an unmodified typeface by Idrees Hassan from [IdreesInc/Monocraft](https://github.com/IdreesInc/Monocraft).
The upstream file is `dist/Monocraft-ttf/Monocraft.ttf` at the release selected by `monocraft` in the Gradle version catalog.
The accompanying `src/jsMain/resources/fonts/OFL.txt` contains its copyright notice and SIL Open Font License.
The demo distributes the font locally so a deployed release does not depend on a font CDN.
