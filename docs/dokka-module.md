# Strata API

Strata is a declarative Minecraft UI library with API-only application authoring, reusable layout and profile-backed components, a retained JVM engine, headless rendering, and versioned client Fabric runtimes.

Start with the [project README](https://github.com/sya-ri/strata/blob/master/README.md), then use the module navigation to inspect the public API.
This site contains the generated API reference.
Reader guides and verified component images are rendered on GitHub in this repository.
