# Strata 0.3.0 (Unreleased)

## Modifier chains

Start modifier chains with `Modifier.size(...)`, `Modifier.padding(...)`, or any custom `Modifier` extension.
The `Modifier` companion object implements the empty chain, so a conditional can use `if (enabled) Modifier.size(100, 40) else Modifier`.
Parent-layout modifiers retain their existing scope restrictions.

`Modifier` is now an interface with an internal implementation for non-empty chains.
Recompile consumers against 0.3.0 and update all Strata artifacts together; compiled calls against the previous class are not binary compatible.
Chain order, read-only snapshots, value comparison, and retained component identity remain unchanged.

## Deprecations

`Modifier.Empty` is deprecated in 0.3.0 with a warning and an IDE replacement of `Modifier`.
It remains an alias for the same empty object until its scheduled removal in 1.0.0.
All other currently deprecated public APIs are also scheduled for removal in 1.0.0.
See the [deprecation list](https://github.com/sya-ri/strata/blob/master/DEPRECATION.md) for versions, replacements, and migration examples.
