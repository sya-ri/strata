# Strata 0.2.1

Strata 0.2.1 reduces drawing and CPU raster work for Minecraft screens without changing public APIs or remote communication contracts.
Keep all Strata artifacts on version `0.2.1` and install the Fabric runtime for your exact Minecraft version.

## Rendering performance

Tiled nine-slice images now combine repetitions along source axes that contain exactly one texel.
A one-by-one center emits one drawing command instead of one command per tile.
Sources with multiple texels retain their repeated pattern and partial final tiles; the default `Tiled` mode is unchanged.
Integer and fractional scaling, clipping, transparent and translucent colors, semantics, input, scroll position, and invalidation retain their existing behavior.

CPU rasterization now uses direct row writes for opaque fills and avoids unnecessary blending for opaque pixels.
One-texel image draws reuse the fill path, and opaque sampled images avoid redundant color operations when the source or tint permits it.
These paths preserve the original pixels and add no cache.

In a measured SabMinato fishing challenge fixture, initial drawing commands decreased from 387,223 to 467.
The reduction depends on the source texture and screen contents; patterned sources with two or more texels still require tiling.
See the [performance contract](https://github.com/sya-ri/strata/blob/v0.2.1/docs/development/performance.md) for measurement and parity requirements.

## Upgrade

Existing screen definitions require no API migration from 0.2.0.
Update Maven dependencies and the installed Fabric runtime together to `0.2.1`.
The runtime continues to support the existing Minecraft version matrix.
