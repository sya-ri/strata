# Strata 0.1.1

Strata 0.1.1 adds support for Minecraft 1.20.
This is the only functional change from Strata 0.1.0; the public API, common runtime behavior, built-in components, and authoring guidance are unchanged.

## Install

Compile application UI source against the API, then install exactly one Fabric runtime matching the active Minecraft version together with Fabric Language Kotlin:

```kotlin
dependencies {
    compileOnly("dev.s7a.strata:strata-api:0.1.1")
    modRuntimeOnly("dev.s7a.strata:strata-runtime-minecraft-fabric-<minecraft-version>:0.1.1")
    modRuntimeOnly("net.fabricmc:fabric-language-kotlin:<compatible-version>")
}
```

The consuming Mod must require Strata in `fabric.mod.json`:

```json
{
  "depends": {
    "strata": ">=0.1.1"
  }
}
```

## Minecraft compatibility

The supported release floor is now Minecraft 1.20.
The complete supported matrix is Minecraft 1.20 through 1.20.6, Minecraft 1.21 through 1.21.11, 26.1, and 26.2.
The Minecraft 1.20 runtime targets Java 17.

## Distribution

The aligned 0.1.1 release republishes the complete supported matrix so every runtime uses the same Strata version even though Minecraft 1.20 is the only newly supported game version.

- Maven Central contains 25 coordinates: the four common artifacts and 21 versioned Fabric runtimes.
- GitHub Releases contains 21 runtime JARs, 21 detached signatures, and `SHA256SUMS`.
- Modrinth contains one 0.1.1 version entry for each of the 21 exact Minecraft versions.

Minecraft 1.19 and older releases remain outside the project scope.
