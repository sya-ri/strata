# Strata 0.1.1

Strata 0.1.1 expands the platform-neutral UI toolkit with Unicode and resource-pack fonts, multiline text editing, wrapping layout, extensible canvases, retained sampled-image acceleration, tiled pan-and-zoom images, and typed player-head scaling.
It also adds a Minecraft 1.20 runtime while keeping every common and versioned runtime on one aligned release.

## Install

Compile application UI source against the API, then install exactly one Fabric runtime matching the active Minecraft version together with Fabric Language Kotlin:

```kotlin
dependencies {
    compileOnly("dev.s7a.strata:strata-api:0.1.1")
    modRuntimeOnly("dev.s7a.strata:strata-runtime-minecraft-fabric-<minecraft-version>:0.1.1")
    modRuntimeOnly("net.fabricmc:fabric-language-kotlin:<compatible-version>")
}
```

The consuming Mod must require Strata in `fabric.mod.json`:

```json
{
  "depends": {
    "strata": ">=0.1.1"
  }
}
```

## Layout, media, and navigation

`FlowRow` measures each child once, wraps exact-fit rows, and supports checked horizontal and vertical gaps, per-row arrangement, and child vertical alignment without synthetic retained parents.

`Canvas` embeds immutable CPU images, leased native textures, or per-attachment custom offscreen renderers in an explicitly sized component.
Native resources use bounded ownership, capture and consumption fences, deterministic retirement, and fail-closed terminal handling.
General captured pointer input supports drag and release delivery after the pointer leaves component bounds.

`DrawCommand.SampledImage` lets supported Fabric runtimes retain decoded images as bounded native textures instead of rerasterizing and uploading the whole viewport when only placement changes.
Portable rendering remains available for unsupported sources and capacity pressure.

`TiledImage` composes multiresolution tile sources with a bounded visible and overscan working set.
`PanZoomState` provides anchored zoom, fit modes, clamping, and world-to-local transforms while tile subscriptions follow the viewport.
Application-owned generation and invalidation remain outside the component cache.

`PlayerHeadScale` expresses a positive integer skin-texel scale directly: `PlayerHeadScale(1)` renders an 8 by 8 head, and larger factors keep every source texel equal in size.
The existing arbitrary `size` overload remains binary compatible but is deprecated; sizes divisible by eight retain nearest sampling and other accepted sizes use bounded region-clamped bilinear interpolation for the face and hat layers.

## Text and fonts

Text, common labels, tooltips, TextField, and TextArea can select resource-pack fonts.
TextField remains a single-line editor; TextArea adds canonical LF values, visual-line navigation, a typed viewport, and vertical scrolling through its state-owned ScrollState.
Both edit at Unicode code-point boundaries and keep IME composition events supplied by Minecraft separate from the committed value.
Existing Text calls remain single-line; the required TextLayout.Multiline overload wraps to parent constraints with word or character wrapping, line limits, clipping or ellipsis, and line spacing.
See the [text guide and compiled examples](https://github.com/sya-ri/strata/blob/master/docs/text.md) for editing and layout contracts.

The optional `strata-runtime-minecraft-fonts-lwjgl` CPU backend renders supplied font resources without launching Minecraft.
Glyph coverage, including emoji, follows the selected Minecraft font resources; this release does not add system fonts or a separate color-emoji engine.
Resource loading enforces explicit size and work budgets, and ordinary Fabric screen opens reuse one immutable profile generation until resource reload.
Signed and signed-zero TrueType settings follow the selected native provider, subject to the [documented numeric safety boundary](https://github.com/sya-ri/strata/blob/master/docs/font-resources.md#numeric-provider-settings).
Native metrics and raw glyph data remain exact acceptance requirements.
Fabric and headless output match exactly at tested scales; final native image differences are accepted only with independent GPU evidence.
The [acceptance scope](https://github.com/sya-ri/strata/blob/master/docs/font-resources.md#acceptance-evidence) identifies tested resources, targets, and device qualifications.

## API migration from 0.1.0

This release intentionally adds `UiText.WithFont` and `DrawCommand.SampledImage` to existing sealed hierarchies.
Exhaustive Kotlin visitors need the new cases before recompilation, and previously compiled visitors can fail when a new case reaches them.
Existing JVM signatures, component overloads, and TextStyle remain available; that does not make old exhaustive visitors source or behavior compatible.
Custom rendering backends need the fractional sampled-image contract even for ordinary Text calls using the default resource-font profile.
Update custom visitors and keep all Strata artifacts aligned; the supplied Fabric and headless backends handle the new cases.
See [Source compatibility](https://github.com/sya-ri/strata/blob/master/docs/text.md#source-compatibility) for migration details.

## Minecraft compatibility

The supported release floor is now Minecraft 1.20.
The complete supported matrix is Minecraft 1.20 through 1.20.6, Minecraft 1.21 through 1.21.11, 26.1, and 26.2.
The Minecraft 1.20 runtime targets Java 17.

## Distribution

The aligned 0.1.1 release publishes the complete supported matrix so every runtime uses the same Strata version.

- Maven Central contains 26 coordinates: the five common artifacts, including the optional `strata-runtime-minecraft-fonts-lwjgl` CPU backend, and 21 versioned Fabric runtimes.
- GitHub Releases contains 21 runtime JARs, 21 detached signatures, and `SHA256SUMS`.
- Modrinth contains one 0.1.1 version entry for each of the 21 exact Minecraft versions.

Minecraft 1.19 and older releases remain outside the project scope.
