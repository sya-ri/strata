# Strata 0.3.4

Strata 0.3.4 adds configurable content dragging and inertia to scroll viewports, direct scrollbar interaction, and optional wheel cycling for CycleButton.
These notes describe changes from public 0.3.3.

## Upgrade requirements

Update Strata artifacts together to `0.3.4` and keep the Fabric runtime matched to the exact Minecraft version.
Remote CycleButton, ScrollArea and VirtualList now use version 2 schemas; update remote hosts and clients together.

Content dragging and inertia are enabled by default, including for existing `ScrollState()` calls.
Buttons and actionable rows inside these viewports activate on a stationary release instead of the initial press.
Use `DragScrollOptions.Disabled` when the screen requires immediate child presses.

## Content dragging and inertia

Start a primary-pointer drag on viewport content, including buttons and actionable rows.
Vertical motion at the configured threshold cancels the pending action and scrolls the content; releasing a stationary tap over the original item activates it.
Horizontal sliders retain horizontal dragging and yield vertical motion to the scroll viewport.
Captured dragging continues outside the viewport until release.

Released flicks decelerate on timed frames.
Pressing a moving viewport stops it without activating the pressed item.
Boundaries, navigation, state replacement and closing the screen cancel momentum.

Configure and retain the scroll state outside reevaluated UI content:

```kotlin
// Disable content dragging.
val wheelOnly = ScrollState(dragScroll = DragScrollOptions.Disabled)

// Drag the content and stop immediately on release.
val dragOnly = ScrollState(
    dragScroll = DragScrollOptions.Enabled(inertia = DragScrollOptions.Inertia.Disabled),
)

// Increase the drag threshold and stop a released flick sooner.
val tuned = ScrollState(
    dragScroll = DragScrollOptions.Enabled(
        dragThreshold = 8.0,
        inertia = DragScrollOptions.Inertia.Enabled(deceleration = 12.0),
    ),
)
```

These types are in `dev.s7a.strata.component`.
Pass the state to `ScrollArea`, or through `VirtualListState(scrollState = tuned)` to `VirtualList`.
The default threshold is 4 viewport-local logical pixels, and the default exponential velocity-decay rate is 9 per second.
Both values must be finite and positive; a larger decay rate stops motion sooner.
The sealed policy exposes inertia only when dragging is enabled, and a decay rate only when inertia is enabled.
Wheel input, keyboard navigation and independent scrollbars remain available with any policy.

See [screens and state](https://github.com/sya-ri/strata/blob/v0.3.4/docs/guides/screens-and-state.md) and the [compiled example](https://github.com/sya-ri/strata/blob/v0.3.4/integration/api/src/main/kotlin/dev/s7a/strata/integration/consumer/ConfiguredScrollDefinition.kt) for complete component calls.

## Scrollbars and CycleButton

Independent scrollbars support track clicks and thumb dragging, retaining the grab position while the pointer moves outside their bounds.
They are separate from content dragging.

CycleButton keeps Minecraft wheel cycling enabled by default.
Set `scrollEnabled = false` to leave wheel input available to an ancestor scroll container:

```kotlin
CycleButton(selection, width = 150, scrollEnabled = false)
```
