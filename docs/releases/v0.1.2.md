# Strata 0.1.2

Strata 0.1.2 corrects the retained presentation path for standard Minecraft images and player heads.
It keeps the 0.1.1 API and rendering contracts while allowing supported Fabric runtimes to retain these immutable images as native textures instead of rebuilding the whole portable viewport when only placement changes.

## Install

Compile application UI source against the API, then install exactly one Fabric runtime matching the active Minecraft version together with Fabric Language Kotlin:

```kotlin
dependencies {
    compileOnly("dev.s7a.strata:strata-api:0.1.2")
    modRuntimeOnly("dev.s7a.strata:strata-runtime-minecraft-fabric-<minecraft-version>:0.1.2")
    modRuntimeOnly("net.fabricmc:fabric-language-kotlin:<compatible-version>")
}
```

The consuming Mod must require Strata in `fabric.mod.json`:

```json
{
  "depends": {
    "strata": ">=0.1.2"
  }
}
```

## Retained image presentation

The standard Minecraft `Image` component now emits `DrawCommand.SampledImage` for its selected source region and logical destination.
Supported Fabric presenters can therefore retain the immutable image in their bounded device-owned texture cache and draw placement-only changes without a full portable viewport upload.
Headless rendering continues to use the same portable command and nearest final-density sampling contract.

`PlayerHead` uses the same sampled-image path for the base face and optional hat.
Sizes expressed with `PlayerHeadScale` retain the normalized 64 by 64 skin and the exact Minecraft face and hat source regions, preserving equal source-texel sizes and face-before-hat composition.
Accepted legacy sizes not divisible by eight still use the bounded region-clamped premultiplied bilinear image introduced in 0.1.1; that derived image is now retained through `SampledImage` as well.
Transparent hat pixels remain composited without an alpha discard threshold.

## Compatibility with 0.1.1

This patch does not add or remove public API members.
It changes the draw-command variant produced by standard `Image` and `PlayerHead` runtime implementations from integer `BlitImage` to `SampledImage`.
Custom backends must already support or explicitly reject `DrawCommand.SampledImage`, which became part of the sealed command hierarchy in 0.1.1.
Keep all Strata artifacts aligned on 0.1.2.

## Minecraft compatibility

The supported matrix remains Minecraft 1.20 through 1.20.6, Minecraft 1.21 through 1.21.11, 26.1, and 26.2.
Minecraft 1.20 uses Java 17, the Minecraft 1.21 family uses its declared Java 21 boundary, and 26.x uses Java 25.
