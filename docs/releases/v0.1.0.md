# Strata 0.1.0

Strata 0.1.0 is the first public release of the platform-neutral authoring API, retained runtime, headless renderer, and separately installed client Fabric runtime.

## Use it

Compile application UI definitions against `dev.s7a.strata:strata-api:0.1.0` and install exactly one `strata-runtime-minecraft-fabric-<minecraft-version>:0.1.0` Mod matching the client together with Fabric Language Kotlin.
Open a one-shot definition through `ScreenDefinition.open()` or Java's `Screens.open(definition)`; ordinary UI source does not import a runtime implementation or receive `MinecraftUiContext`.
The [compiled API-only opening example](https://github.com/sya-ri/strata#api-only-open-example) is the canonical snippet reused by the public skill and release-page metadata.

The supported Minecraft range is 1.20.1 through 1.21.11 plus 26.1 and 26.2.
Minecraft 1.19 and older versions are outside the release scope.

## Highlights

- Structural Row, Column, Grid, and intentional-overlap Stack layout with arrangement, alignment, spacing, weight, checked constraints, and active modifiers.
- Text, TextField, Button, Checkbox, generic CycleButton, Slider, Tab, ScrollArea, independent Scrollbar, VirtualList, SelectionList, Image, Slot, PlayerHead, LoadingIndicator, and ProgressBar components.
- Leading and trailing infinite-list requests, index and stable-key jumps, resource-pack images and backgrounds, profile-driven player heads, and synchronized player, container, ender-chest, furnace, or custom-menu slot bindings.
- Public Element and Node SPI for downstream retained primitives, while purpose-specific Mod components remain ordinary compositions.
- Deterministic headless PNG and semantics output, loaded Minecraft native/Fabric/headless comparisons, real inventory interaction, and render/retention measurements.

## Verification

The release commit passes Kotlin explicit API mode, warnings-as-errors, ABI validation, Detekt, Kotlinter, Qodana, JVM tests, Kover reports, all supported loaded-client suites, published-coordinate consumer tests, generated-skill checks, link and asset checks, and publication metadata inspection.
Component documentation images are complete dedicated `ScreenDefinition` frames rather than crops from a larger showcase.

## Distribution

- Maven Central contains `strata-api`, the common runtime modules, and all 20 versioned Fabric runtime artifacts with sources, Javadoc, signatures, Gradle metadata, and MIT license files.
- The GitHub Release contains the same canonical 20 runtime JARs, detached signatures, checksums, and these notes.
- [Modrinth](https://modrinth.com/mod/strata-ui) contains one client-only Fabric release entry per exact Minecraft version and declares Fabric Language Kotlin as required.
- The public [`skills/strata`](https://github.com/sya-ri/strata/tree/v0.1.0/skills/strata) package contains mechanically checked API signatures and Strata-specific authoring guidance.

Generative AI substantially assisted implementation, review, tests, documentation, and release-page text.
The maintainer directed the design and validates release artifacts through the public test suite.

## Known limitations

- The verified bitmap font path supports printable ASCII with the regular Minecraft glyph sheet.
- Forced Unicode and multi-resource font stacks are not supported in this release.
- Resource-backed images keep their declared logical dimensions when a resource pack replaces their pixels.
