# Strata 0.3.3

Strata 0.3.3 adds component tooltips, optional tooltip decoration and Web tooltip support, and fixes Minecraft tooltip backgrounds around short labels.
These notes describe changes from public 0.3.2.

## Upgrade requirements

Update Strata artifacts together to `0.3.3` and keep the Fabric runtime matched to the exact Minecraft version.
Remote component tooltips and explicit decoration settings require clients supporting the new negotiated tooltip schemas.

## Text and component tooltips

Use `Modifier.tooltip("Explanation")` for a label or `Modifier.tooltip { ... }` for a component tree containing text, images and layouts.
Component content must emit one root; group multiple components in a layout such as `Column`.
The content remains display-only and cannot receive pointer input or focus.

Both forms use the runtime's standard tooltip background, frame and three-pixel content inset by default.
Set `decorated = false` to display only the supplied content.
Minecraft uses its native tooltip design, and Web uses the active theme's standard surface.
Minecraft tooltip sprites retain their native outer margin so the background and frame remain visible around short, single-line labels.

The default hover delay remains 500 milliseconds; `delayMillis = 0` displays content immediately.
Tooltips follow their target, escape ancestor clips and fit within the screen without changing the target's layout size.
Content updates preserve the hover delay and refresh retained content while hidden or visible.

See [tooltips](https://github.com/sya-ri/strata/blob/v0.3.3/docs/guides/modifiers.md#tooltips) for examples and runtime capability requirements.

## Server plugin downloads

GitHub Releases now include installable Paper/Folia and Velocity plugin JARs with their original signatures alongside the Fabric artifacts.
Folia uses the Paper plugin JAR.
