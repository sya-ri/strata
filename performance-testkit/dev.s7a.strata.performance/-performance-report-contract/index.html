PerformanceReportContract

data class PerformanceReportContract(val workloadId: String, val phaseKeys: List<String>, val phaseCount: Int, val reportConditions: Set<String>, val phaseConditions: Set<String>, val variantReportFields: Set<String> = emptySet(), val variantPhaseFields: Set<String> = emptySet(), val repetitions: Int = 3, val schemaVersion: Int = 1)(source)

Consumer-declared registration for a fixed report workload, independent of collection and comparison. Variant report fields may change between runtime candidates, but must remain identical within a side. Phase conditions must include sample counts and every fixture invariant required by that workload.
